初回手順
1. index.html を開く
2. 同期・設定 → バックアップ読込 から、正しい661種類/675個体の shiny-home-backup.json を読み込む
3. 表示が661/675であることを確認
4. 必要なら「旧版画像をコピー」で旧IndexedDBの画像をコピー
5. 「安全状態を確認」で安全Vaultを確認

設計
- 旧版とは別の localStorage / IndexedDB 名を使用
- Service Workerを登録しない
- 自動クラウド同期/自動クラウド復元をしない
- Supabaseは手動保存・手動読込のみ
- ポケモン対象データは固定。外部CSV失敗で対象数が変わらない
- 自動安全Vault: IndexedDBに最大20世代
- 画像は別IndexedDB
